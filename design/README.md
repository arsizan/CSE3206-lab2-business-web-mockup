# Northline — Lab Question 2

A complete professional-services website design concept for CSE 3206, Web Engineering Sessional. Only Question 2 is covered.

## Deliverables

- Four pages: Home, About, Services, and Contact.
- Desktop layouts at 1440 px and mobile layouts at 390 px.
- High-fidelity mockups and low-fidelity wireframes: 16 screens in total.
- A native Figma importer that creates organised, editable frames, live text, image fills, vectors, shared colour and text styles, and reusable components.
- Editable SVG versions of all 16 layouts.
- Original photography assets and a script-ready lab answer.

## Get an editable Figma source file

The ZIP is a Figma **import kit**, not an already-exported `.fig` file. No screenshot is being passed off as editable source.

1. Unzip the download.
2. Open **Figma desktop** and create a new design file.
3. Choose **Plugins → Development → Import plugin from manifest…**.
4. Select `figma-importer/manifest.json`.
5. Run **Northline — Lab 02** from the Development plugins menu.
6. Wait for the importer to finish. It creates three pages:
   - `01 — High fidelity`: four desktop and four mobile mockups.
   - `02 — Wireframes`: the equivalent low-fidelity layouts.
   - `03 — Design system`: shared colours, typography and reusable components.
7. Choose **File → Save local copy…** to download your genuine editable `.fig` file.

The importer runs locally inside Figma. It makes no network requests and does not require API keys. It adds new pages without changing existing layers. Run it in a new file to avoid duplicate pages.

If the font is not available in Figma, the importer falls back to Inter and displays a notification. Install/enable Instrument Serif, Plus Jakarta Sans and JetBrains Mono for the intended typography. All three are public Google Fonts.

## Quick alternative

Drag any file in `svg-layouts` onto a Figma design canvas. These files contain SVG text and vectors, not flattened page screenshots. The importer is recommended because it also sets up native frames, shared styles and components.

## Design direction

Forest green for trust, warm ivory for clarity, and terracotta for a human accent. Instrument Serif headlines pair with readable Plus Jakarta Sans interface text. The hierarchy leads from a clear value proposition to services and a conversation CTA.

Desktop uses two-column editorial sections; mobile stacks the same content with touch-friendly controls. Contact includes labelled required fields, a service selector and a demo success state. Navigation, buttons and service links are interactive in the web prototype.

## Scope and honesty

- Northline and all partner wordmarks are fictional demonstration brands. No genuine customer endorsements or business-performance claims are implied.
- The contact details are illustrative. The form demonstrates validation and completion only; it sends and stores nothing.
- The linked client brief requests high-fidelity mockups; the lab sheet additionally lists low-fidelity mockups. Both are provided.
- A native `.fig` binary cannot be exported directly from the Make coding environment. The supplied importer creates editable source in Figma, from which Figma can save the file.
- Website implementation, hosting, email delivery, accounts and ongoing CMS functionality are outside this design-only lab scope.
